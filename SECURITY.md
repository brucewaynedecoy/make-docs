# Security policy

## Supported versions

Maintainers review security reports for the current npm release and the `main` branch. Older releases may not receive fixes. Check the [npm package](https://www.npmjs.com/package/@brucewaynedecoy/make-docs) for the current published version.

## Private reports

Use [GitHub private vulnerability reporting](https://github.com/brucewaynedecoy/make-docs/security/advisories/new) to report a suspected flaw. Include the affected version, steps to reproduce, and the likely effect. Do not post the details in a public issue or pull request.

Maintainers will review the report and coordinate any fix and disclosure through the private advisory. We do not promise a fixed response or release date.
