# Phase 3: Backlog-Review Bundles

## Purpose

Apply design decision OD-1 option A to the `backlog-review` Skill. Its logic gets one home in CLI source, and the portable no-CLI path stays. This phase depends only on the PRD pass and can run beside P1 and P2.

## Overview

`collect-project-lead-context.mjs` and `render-report.mjs` are hand-written today. This phase moves their logic into CLI source and builds them as generated bundles, as the other two files in `packages/skills/backlog-review/scripts/` already are. A test proves that each file matches a fresh build byte for byte.
