## Coverage and Authoring Rule

Standard agent locations own installed Skill files. The global Make Docs Store owns installation state. `packages/skills/<name>/` owns authoring source. Do not add a private `.make-docs` Skill layer or treat a Make Docs resource URL as a filesystem symlink target. This rule must remain in current package and PRD guidance because the same wrong layout had already caused a prior installation to be removed.

System instructions are corrected upstream; installed copies change only through the public CLI. Project guides are corrected in place. No new phase, test framework, deferred URL feature, or local state file is introduced. Final package/tree, migration, real CLI and public review evidence must replace the affected gates before owner review.
