# Lifecycle Archive Router

`docs/archive/**` is the planned canonical archive namespace for lifecycle artifacts.

- Current archives remain under `docs/assets/archive/**` until a dedicated migration phase moves or maps content.
- Do not pre-create archive subtype directories here. Create them only when an explicit archive operation needs them.
- When migrating archived content here, preserve lineage links from the old `docs/assets/archive/**` path and record the migration in `docs/assets/history/`.
- History placement remains `docs/assets/history/**` until a later PRD/work phase changes it explicitly.
