# Make Docs 2.0.6 release notes — draft

These notes cover the changes since 2.0.5. They are for release review. Version 2.0.6 is not published.

## Checkout moves

- Setup now finds a moved project before it offers a fresh install. It shows the saved source path, the new target path, the project ID, and any reason that stops the move.
- A move needs a review of one source checkout and an exact approval. The move keeps the checkout ID, project ID, installation ledger, and prior work history. A second run does not make another move.
- A root project and a kit inside it have separate IDs. Review and move each target on its own. A root move does not move the kit's Store record.
- A separate checkout uses its own reviewed action and gets a new checkout ID. It does not take ownership from the original checkout.

## Managed file ownership

- Make Docs now checks the content inside its managed blocks in `AGENTS.md` and `CLAUDE.md`. Text before or after a valid block can change without blocking a move.
- Make Docs still checks the full content of a fully owned file. A changed block, bad block marker, missing ownership fact, unsupported proof version, active writer, pending work, live old path, or target claim stops the move. The tool gives a next step and keeps the saved binding.
- A review becomes stale if the config or reviewed target files change before approval. Preview, dry run, and refusal do not write a move record.

## Upgrade notes and limits

- The 2.0.5 package can seed the old installation. After a 2.0.6 move, use the new package for later moves. The 2.0.5 tool refuses unfamiliar move evidence on a further relocation. This check does not claim downgrade support.
- Test a move in a disposable project and Store before work on a live project. Review a root and each nested kit as separate targets.
- The 2.0.5 GitHub Copilot client limit still applies. Direct Windows and Linux client use and a same-name app entry remain unproved. The W25 speed and scale waiver makes no speed or scale claim.
- The final 2.0.6 tarball passed the installed upgrade and package checks on macOS with Node.js 24.19.0 and npm 11.17.0. Real Windows and Linux host checks, open GitHub alert review, and release approval remain pending. No public availability is claimed.
