# Make Docs 2.0.5 security review

**State:** local assessment for release review. Version 2.0.5 has not been published. The release follow-up merged as PR #43, and W25 merged as PR #49. GitHub alert status and package checks need a fresh read before publication. This record does not claim a current alert count.

## Scope and evidence

- The release guide requires high-severity alerts to be resolved or assessed before release. A live GitHub read on 2026-10-24 found 15 open dependency alerts: one critical, five high, eight medium, and one low. It found 30 open code alerts: two high and 28 medium. These alerts describe the merged source before the local fixes in this review.
- The publishable package runs its MCP server over stdio. Its server source does not set up Express, an HTTP transport, OAuth client, or experimental task store. The package still depends on the MCP SDK, so the dependency tree needs review.
- An offline install from the updated lockfile resolved `@modelcontextprotocol/sdk` 1.32.2, `proxy-addr` 2.0.8, and `source-map-js` 1.2.2. The package build, type check, 11 Python tests, and 34 focused TypeScript tests passed. The full `npm test` run passed 19 smoke tests and 1,682 CLI tests. Five CLI tests were skipped by their existing test setting. No test failed.
- The 2.0.5 package dry run passed with 139 files. It included the built CLI entry, template, and embedded Skill bundle. PRD authority validation scanned 35 PRDs and 1,142 links with no finding. Local links in these review files passed.
- The tracked Backlog Review Skill copy in `.agents/` matches its source asset byte for byte. The two CodeQL fixes match the exact messages on alerts 1 and 2.

## Other open alerts

- The two medium MCP SDK alerts are covered by the move to 1.32.2. One concerns HTTP redirects in clients. The other concerns bearer checks on an HTTP server. Neither feature runs in the stdio server.
- The medium [Hono static-file alert](https://github.com/advisories/GHSA-5r4p-p66f-jhc7) needs an HTTP static-file route with protected path middleware. Make Docs does not start that route. It remains in the runtime dependency tree and needs a fresh alert check after the next dependency update.
- The other medium dependency alerts concern the development test tools Vite, Vitest, and its mocker. The low alert concerns the development build tool esbuild. They are not paths in the published stdio server. The 28 medium CodeQL alerts point to test files, not published source or Skill assets.
