## Outcome

One exact installed version displays the complete real report, refreshes correctly, and sends Explain and Work requests to the original connected agent chat. The working package and connection remain available for the user's trial. The final summary names the proved host and every remaining host limit. Source tests alone cannot prove this outcome.

Use an ordinary disposable project copy for controlled changes and harmless work. Create no Git branch or worktree.

8. Inspect installed keyboard, focus, narrow-width, themes, Data height, print, and recovery. Leave a stable launch path and connection. Offer one advisory normal-use trial. Prepare one closeout summary. Do not close P7, commit, push, or publish before separate authority.
