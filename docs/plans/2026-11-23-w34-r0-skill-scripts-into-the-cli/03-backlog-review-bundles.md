# W34 R0 P3 Backlog-Review Bundles

## Purpose

Apply owner decision OD-1 option A to the `backlog-review` Skill. Its logic gets one home in CLI source, and the portable no-CLI path stays.

## Outcome

All four files in `packages/skills/backlog-review/scripts/` are generated bundles of CLI source. A test proves that each file matches a fresh build byte for byte.

## Scope

- Move the logic of `collect-project-lead-context.mjs` into CLI source next to the backlog presentation code under `packages/cli/src/operations/work/backlog/`. It keeps the R-BACKLOG-SKILL-21 behavior: the same source order, bounded excerpts, repository-relative paths, and content hashes.
- Move the logic of `render-report.mjs` into CLI source in the same way.
- Extend `packages/cli/scripts/build-backlog-presentation.mjs` to write both files with the "Generated by ... Do not edit." header that the other two files have.
- Keep each file usable with Node built-ins only, with no CLI, `node_modules`, Store, or network, as the Skill README says today.
- Add a test that builds all four files fresh and compares their bytes with the files in `packages/skills/backlog-review/`.
- Keep the current tests of the collector and the render wrapper. Add tests for any case that the move exposes.
- Update this repository's installed copy at `.agents/skills/backlog-review/` through the public CLI, with `make-docs update` or `make-docs setup skills`. Do not copy files by hand. `.claude/skills/backlog-review` links to that copy.

## Exclusions

- No change to the report model, the snapshot, or the cache.
- No new registry operation. The collector stays a Skill bundle.

## Acceptance

- The byte-match test passes for all four files, and fails when one byte changes.
- The backlog-review Skill tests pass with the generated files.
- The installed dogfood copy matches the source bytes.

## Testing Decisions

- Automated Implementation Testing: required.
- Performance Testing: `not-needed`.
- Guided Progress Review: `not-needed-now`.
- Unassisted Goal Testing: `not-needed-now`.

## Dependencies

- The PRD pass for PRD 51 R-BACKLOG-SKILL-21.
- It can run beside P1 and P2.
- Merge risk with W29 R0 P4, which changes the backlog presentation source. After either merge, rebuild the bundles and rerun the byte-match test.
